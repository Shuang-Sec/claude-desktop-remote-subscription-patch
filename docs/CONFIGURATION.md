# Configuration

All scripts read `config.json` from the repository root unless
`CLAUDE_PATCH_CONFIG` points elsewhere. Use `config.example.json` as the
template.

## Fields

| Field | Required | Default | Notes |
|---|---|---|---|
| `officialApp` | yes | — | Path to the official Desktop `app` directory containing `claude.exe` and `resources/app.asar` |
| `officialProfile` | yes | — | Official 3P profile directory; contains `configLibrary` |
| `trialRoot` | no | `./trial` | Output directory for the independent copy |
| `version` | no | `4.4212.0` | Documentation/record only; must match the official app |
| `modelCatalogFile` | no | `./trial/remote-models.json` | Generated by `refresh-remote-models.ps1` |
| `providerConfigFile` | no | auto-discover | A specific `configLibrary/<uuid>.json` |
| `ssh.alias` | no | `claude-remote` | Display name only |
| `ssh.user` | yes | `deploy` in example | SSH user |
| `ssh.host` | yes | — | Server hostname/IP |
| `ssh.port` | no | `22` | SSH port |
| `ssh.identityFile` | yes | — | Windows private key path |
| `ssh.remoteCwd` | no | `/home/<user>/project` | Initial remote folder |
| `ssh.testCwd` | no | `/home/<user>/claude-remote-test` | Model initialize working directory |
| `ssh.desktopCli` | no | auto-discover | Explicit `~/.claude/remote/ccd-cli/*` path |
| `nodePath` | no | `node` | Custom Node executable |
| `usagePanel` | no | `true` | Enable the remote usage panel |

## Path resolution

- Absolute paths are used as-is.
- Relative paths resolve from the repository root.
- `config.json` itself is ignored by git.

## Provider config

`prepare.mjs` copies `officialProfile/configLibrary` into the trial profile.
`build.mjs` discovers the provider JSON there:

- if `providerConfigFile` is set, it is used;
- otherwise exactly one `[0-9a-f-]{36}.json` is allowed (excluding `_meta.json`);
- multiple provider files require `providerConfigFile`.

The sealed gateway key is copied only into the local trial profile. It is never
committed or printed.

## SSH host allow-list

`prepare.mjs` writes `trial/profile/ssh_configs.json` with:

- `sshHost = "<user>@<host>"`;
- the configured key path;
- `remoteCwd`;
- `trustedHosts = [host, "<user>@<host>"]`.

The patch also sets the Desktop host allow-list to the configured host only.

## Model catalog

`refresh-remote-models.ps1` writes `remote-models.json` and its previous copy.
`apply-model-menu.mjs` writes the menu into the provider config. The Fable 5.2
entry gets `supports1m`/`prefer1m`.

Do not edit `remote-models.json` by hand for a production menu; use the refresh
script so both engines are checked.

## Environment overrides

- `CLAUDE_PATCH_CONFIG` — path to config JSON.
- `CLAUDE_PATCH_SSH_HOSTS` — comma-separated host list for unit tests; build
  scripts inject the real list and do not require this variable.

## Validation

`loadConfig()` rejects:

- missing/non-string official paths;
- missing SSH host or identity file;
- invalid SSH port;
- missing config file;
- malformed JSON.

It does not require the files to exist; `install.ps1 -Check` and the build
scripts do that.
